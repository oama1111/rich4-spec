**`0x416355`（地產页的三行）**

```asm
00416355  mov ebx, 1 / mov eax,[0x498e84] / add eax, 0x34   ; 地块表 + 0x34
00416372  mov ebp, [0x498e98]                               ; 地块个数
00416378  cmp ebx, ebp / jg 0x4163a2
0041637c  mov dl, byte [eax+0x19] / lea ecx,[esi+1] / cmp edx,ecx / jne  ; owner == 玩家+1
00416388  inc dword ptr [esp+0xac]                          ; ← 土地 计数
0041638f  cmp byte [eax+0x18], 0 / je …                     ; 类型 != 0
00416395  inc dword ptr [esp+0xa8]                          ; ← 連鎖店 计数
; 004163a2 起同样一轮走設施表 [0x498e88]（步长 0x38、个数 [0x498e8c]）
004163c7  inc dword ptr [esp+0xac]                          ; 設施也算「土地」
004163ce  cmp byte [eax+0x1a], 0 / je …                     ; 等级 != 0

```

- 三个计数：`[esp+0xac]` = **地块（owner 匹配）+ 設施（owner 匹配）**，`[esp+0xa8]` = **地块里类型 `+0x18`≠0 的**，
  `edi` = **設施里等级 `+0x1a`≠0 的**（@source `0x416388` / `0x416395` / `0x4163c7` / `0x4163d4`）。
- 循环都是 **1-based**（`ebx` 从 1，指针先 `+0x34`/`+0x38`），上界取各自个数全局（@source `0x416372`/`0x4163b1`）。
- 行序 = **土地 / 連鎖店 / 設施**，三行都用 `itoa`（@source `panel.ts:37-38` 与 `panel.test.ts:64`
  的「`estate[0]` = 2 块地 + 1 个设施 = 3（VA 0x00416355 的 `[esp+0xac]`）」，C 级）。
- 后 36 条（三条串的生成与三个落点）不在 pack 内 → `### 未决`。同类四页处理函数是
  `0x004162d4`（資金）/`0x00416355`（地產）/`0x0041646c`（股票）/`0x004165e1`（其他）
  （@source `hud.ts:918`、`panel.ts:16`）。

**文字对齐的四个片段（`0x44ff21` / `0x44ff2a` / `0x44ff42` / `0x44ff4b`）**

- 它们是 `_rich4_draw_text`（VA `0x44fabc`）末段那条 **7 路跳表**的四个落点；跳表本体在 `0x44faa0`，
  按 `flag − 1` 索引（@source `hud.ts:103-104`）。跳表映射（C 级，据 `hud.ts:107-114`）：

| flag | 落点 | 算式（A 级，见下）| 效果 |
|---|---|---|---|
| 1 | `0x44ff21` | `x −= 宽` | 右上 |
| 2 / 3 / 4 | `0x44ff2a` → `0x44ff35` | `x −= 宽/2`；`y −= 高/2` | 正中 |
| 5 | `0x44ff35`（不在清单内）| 只 `y −= 高/2` | 左·垂直居中 |
| 6 | `0x44ff42` → `0x44ff35` | `x −= 宽`；`y −= 高/2` | 右·垂直居中 |
| 7 | `0x44ff4b` | `x −= 宽/2`；`y −= 高` | 水平居中·底对齐 |

- `esi` = 文字宽 + 1、`ebx` = 文字高 + 1，`[esp+0xac]` = x、`[esp+0xb0]` = y（@source `hud.ts:105`）。
- **`0x44ff2a` 之所以两轴都居中，是因为 `0x44ff2e` 那条 `sub` 之后没有跳转，直接落到 `0x44ff35`**
  （@source `0x44ff2a`–`0x44ff40`：`mov eax,esi / sar eax,1 / sub [esp+0xac],eax` 紧接
  `mov eax,ebx / sar eax,1 / sub [esp+0xb0],eax`）；flag 3 与 flag 2 指向同一段，故行为一致。
- `0x44ff42` 与 `0x44ff21` 只差跳转目标：前者 `jmp 0x44ff35`（再减半个高），后者 `jmp 0x44ff5d`（直接收尾）
  —— @source `0x44ff49` vs `0x44ff28`。
- `0x44ff4b` 没有跳转，`sub dword ptr [esp+0xb0], ebx`（7 字节到 `0x44ff5d`）就是顺落收尾
  （@source `0x44ff56`）。

| `0x4079f9` | 51B | 绘制槽排序比较器：**只比低 16 位有符号 int16**，返回 −1 / 0 / +1 | A（比较）＋C（用途）|
