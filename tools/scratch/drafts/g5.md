叙述：

- **四个「逐槽停」的状态（`0x43f55f` / `0x43f57f` / `0x43f59f` / `0x43f5bd`）是同一张模板**，
  只有两个操作数不同，把它们并排看就一眼看穿：

  ```asm
  ; 0x43f55f（状态 4 → 5）        0x43f57f（状态 5 → 6）        0x43f59f（状态 6 → 7）        0x43f5bd（状态 7 → 8）
  0043f55f push 1                 0043f57f push 2                 0043f59f push 3                 0043f5bd push 4
  0043f561 push 0xf               0043f581 push 0xe               0043f5a1 push 0xc               0043f5bf push 8
  0043f563 push ebp               0043f583 push ebp               0043f5a3 push ebp               0043f5c1 push ebp
  0043f564 call 0x43ef3e          0043f584 call 0x43ef3e          0043f5a4 call 0x43ef3e          0043f5c2 call 0x43ef3e
  0043f569 cmp eax, 1             0043f58c cmp eax, 1             0043f5ac cmp eax, 1             0043f5ca cmp eax, 1
  0043f56f jne 0x43f709           0043f58f jne 0x43f709           0043f5af jne 0x43f709           0043f5cd jne 0x43f709
  0043f575 mov esi, 5             0043f595 mov esi, 6             0043f5b5 lea esi,[ebp+7]        0043f5d3 mov esi, 8
  ```

  ⇒ 每个状态的三个实参就是 **`(槽号, 剩余位数的掩码, 第几槽)`**：`(1, 0xf)` → `(2, 0xe)` → `(3, 0xc)` → `(4, 8)`，
  掩码从 `0xf` 逐次抹掉一个 bit（`0xf → 0xe → 0xc → 8`），**这就是「从左往右逐槽停」的写法**。
  `cmp eax,1 / jne 0x43f709` 是「**这一槽没停稳就直接回主循环**（不改状态）」，

  ```asm

  0041e15a mov edx,[0x48be4c]                        0041e191 mov edx,[0x48be4c]
           shl eax,2 / sub eax,edx / add eax,eax              shl eax,2 / sub eax,edx / add eax,eax
  0041e169 mov cl,[eax+0x48be38]                     0041e1a0 mov dh,[eax+0x48be38]
  0041e16f cmp cl,0xa       ; > 10 才减              0041e1a6 cmp dh,0x5a      ; >= 90 即跳

  0041e174 mov dl,cl / sub dl,0xa                    0041e1ab mov bh,dh / add bh,0xa
  0041e179 mov [eax+0x48be38],dl                     0041e1b0 mov [eax+0x48be38],bh
  0041e17f jmp 0x41e2a8                              0041e1b6 jmp 0x41e2a8
  ```

    只见于 `main.ts:2408` 的注释，**未见对应汇编**。本节 `0x410d84` 一行按 **A 级只写那一条**，
    其余分支归 **C 级**（出处为 `main.ts:2408`）。
11. **`0x4106c1` 里「表项 0 = 音效 2 / 表项 1 = 音效 4」这层对应是本轮推出来的**。
    pack 给的是「项号 = `((控件号 − 7) ^ 1) * 8 + 0x10`、基址 `0x48231a`」与「控件 7 = 取消 / 8 = 確定」，
    **表里那两格 dword 的实际数值**（`0x48232a` / `0x482332`）只出现在 `main.ts:2215`、`main.ts:2217` 的注释里。
    ⇒ 「异或 1 ⇒ 两者对调」是 **A 级**（算术在它自身里），「对调后落到音效 2 / 4」按 **C 级**。
12. **`0x410838` 里 `0x48bb58 + 0xa` 那一步没有定义**。pack 只见 `mov edx,[0x48bb58] / add edx,0xa` 之后
    进 12 字节乘法；`[0x48bb58]` 被 remake 注为「入口参数」（`main.ts:2721`），
    但**它到底是按钮序号还是某个记录指针**，本轮没有闭合。

**本段 C 级清单（共 3 个 VA 的局部结论）**：`0x43f351`（音效号、图号）、`0x40defe`（「写状态 2」那一步）、
`0x410d84`（音效表其余分支）；另 `0x4106c1` 的「对调后落到 2 / 4」也是 C。除此之外，表里 29 行的其余结论均为 A 或 B 级。
