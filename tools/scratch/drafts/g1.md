## 二、商店屏 / 遊戲說明屏 / 標題頁选项副屏（20 个）

> 本节收口阶段 1：这些函数 remake 早已引用，PRD 此前未收。全部是**表现层**（画图 / 版式 / 命中），
> 不承载规则。证据等级：**A** = exe 逐字（汇编或表地址可见）；**B** = 由 A 级事实直接推出（括注依据）；
> **C** = 仅 remake 注释转述、本轮未回 exe 复核。凡「A·C」表示一条里既有 A 级也有 C 级子结论，
> 逐条在叙述里分开标注。图号换算法（`12*graph_st`、`图号 = (imm − 0xc) / 12`）引自
> `options.ts` 文件头的 exe 用法核对（@source `options.ts:11` 的「下标 = ctx0 + 0xc + 12*i」），
> 标 B。

#### `0x42d977` 定时器：变脸 / 气泡 / 窗口状态机（656B）

- 入口第一笔就是一次 `blitRect`（`0x4563f5`）——remake 记作「那几张变脸帧走 `fcn_004563f5`，
  **不带透明**，所以换一张就等于把上一张盖掉」（@source 0x42d977；remake 注见 `shop-screen.ts:337`，C）。
  它跑在跳表 `0x42d36b` 的落点上（`loc_0042d87e` 那 5 项，remake 注，C），窗口过程本身是 `0x0042d37f`（`shop-screen.ts:8`）。
- 之后 `[0x48a0e0]` 的 vtbl `+0x80`，接 `push 0 / lea eax,[esp+0x44] / push eax / push edi`（BeginPaint 口径），
  再 `InvalidateRect`（`cs:[0x4622f8]`）。
- `add dword ptr [0x48c32f], 0x10`：**相位推进 16**。remake 把 `[0x48c32f]` 的 bit 8–11 当「上一帧画的脸」
  （`shop-screen.ts:345`，C）；A 级可见的是「每拍 +0x10」。
- `call 0x44ee18`（气泡；同一个 VA 在 pack 里能看到 `timeGetTime` 与 `0x7d0`=2000ms 的比较，说明它就是气泡的到点判断）
  → `test eax,eax / je 0x42dc36`：**返回 0 就直接走出口、不跑下面的状态机**，非 0 才继续。
- 状态机读 `[0x48c318]`：`cmp eax,2 / jb`、`jbe`、`cmp eax,4 / je` —— 可用值 **0 / 2 / 4**：
  `0` → `PostMessageA(hwnd, 0x40c, 0, 0)` 且 `[0x48c318] = 1`；`2` → `[0x48c318] = 3`、
  `byte ptr [eax + 0x48c349] = 1`（eax = `[0x48c310]`）、`push 1 / call 0x402460`；`4` → `loc_0042dc0f`。
  callee 里另有 `USER32!KillTimer`、`rand15`、`sub_0044ef3b`、`sub_00402460`（@source 0x42d977 的 callee 表）。
- remake 补的第二处动画（C；remake 记 `loc_0042dc4c` —— **该地址在 pack 的 callee 表里**，`[0x48c314]` 在 globals 表里）：
  由 `[0x48c314]` 那个倒数器驱动，倒到 0 先画基准帧（图 9 / 图 25），
  随后有 `rand()>>11 < 4`（约 1/4）的机会换成图 10/11 或 26/27，并把倒数重置成 `rand()&7`（抽到 0 就取 1）。
- 落点（C，`shop-screen.ts:355-363`）：卡片页脸 `0x195/0x3c`、嘴 `0x195/0x5b`；道具页 `0x1a1/0x32`、`0x1a1/0x59`
  （remake 记 `loc_0042d911` / `loc_0042dcc0` / `loc_0042d9c6` / `loc_0042dd6e`；其中**只有 `loc_0042dcc0` 与
  `loc_0042dd6e` 在 pack 的 callee 表里**，另两个本轮没有 exe 依据）。

#### `0x44e668` 右列 8 行的逐行命中（131B）

- `[0x476018]` → `eax = 20*章号`（`shl 2 / add / shl 2`），项基址 `0x4761b4`。
  `edx = [eax+0x4761c4]`（= `entry+0x10`，当前偏移）`+ 8` 与 `ecx = [eax+0x4761c0]`（= `entry+0x0C`，资源数）比：
  够 8 则 `ebp = 8`，否则 `ebp = 资源数 − 偏移` —— **可见行数上限 8**。
- 循环（`eax` = 行号 i）：`cmp esi,0x6c / jl` → `esi` 是**局部 x**，须 ≥ 108；`cmp esi,0xc1 / jge` → 须 < 193；
  `edx = 34*i`（`shl 4 / add / add edx,edx`）；`ecx = 34*i + 0x4e`、`cmp ebx,ecx / jl`、`edx += 0x6f`、`cmp ebx,edx / jge`
  → `ebx` 是**局部 y**，须落在 **[78+34i, 111+34i)**。
- 命中即 `[0x47601c] = i + [entry+0x10]`，再 `jmp 0x44e65e`（重画）；没命中 `inc eax` 看下一行。
- 与 remake 的数据模型对得上（C/B 交叉，@source 0x44e668 的 `0x4e`/`0x6f`/`0xc1`）：右列 8 行格图的行距 **34**、落点 `(108, 78+34i)`、
  分项名 `(150, 94+34i)`（`help-screen.ts:44`）——命中框 x∈[108,193) 正是那张 85 宽的格图那一列。
- ⚠️ 本条与 remake 注释「条目 1（上一章 / 下一章）= `loc_0044e668` / `loc_0044e881`」**不符**：asm 里这是
  位置命中 + 写行偏移，没有碰 `[0x476018]`。见「未决」。

#### `0x44e6eb` 共用「贴按下图」+ `0x44e881` 退一屏（182B / 195B）

- `0x44e6eb` 开头：`[entry+0x0C] <= 8` 就 `jle sub_0044e586`（**一章不足两屏就没有可滚的**）。
- 然后 `eax = [0x48c5fc] << 4`，四次「`[0x48c5e4/0x48c5e8] + [eax+0x476254..0x476260]`」取

  也是这么定的（`help-screen.ts:173-175`，C）。
- `0x44e881` 开头同样是 `[entry+0x0C] <= 8` 不滚；再看 `[entry+0x10]`：`≤ 0` → `0x44e8d3` 那一支
  （按 `0x476274/78/7c/80` = 命中表第 2 项 (170,43,192,58) 取矩形，BeginPaint 后重画）；
  `> 8` → 两个变量各 −8；`≤ 8` → `[0x47601c] −= 剩余`、`[entry+0x10] = 0`。两条出口都 `jmp 0x44e65e`。
- `0x44e944` 是它的镜像：`edx = 资源数 − 8`（`max`），`if (max <= 当前偏移)` → `0x44e9a2` 那一支；

- remake 的换算（C，@source 0x44e881 / 0x44e944）：exe 的步长 `8` 是**资源**步长，remake 换成「一屏 14 行」的行步长
  （`help-screen.ts:1719-1722`、`help-screen.ts:1733-1736`），并注明「够走一步就走 8，走不过去就直接落到 max
  （不做取整）」——与本条 A 级 asm 一致。

#### 小区块（日期頁四颗微调 / 两个灯 / 視窗三选一 / 右上角钮）

- 日、月、年三个字段就是 `[0x48bb84]`（日）/ `[0x48bb85]`（月）/ `[0x48bb86]`（年，word），

### 未决

1. **游戏说明屏四支的对应关系未定案。** remake 有两处互相矛盾的注释：`help-screen.ts:92` 说
   「上一章 / 下一章 = `loc_0044e668` / `loc_0044e881`」，`help-screen.ts:1719` 与 `:2300` 又说
   「上滚 / 下滚 = `loc_0044e6eb` / `loc_0044e944`」、并把 `0x44e668` 记成「退 8 行」。按 asm：
   `0x44e668` 是**按鼠标位置**逐行命中（写 `[0x47601c]`，不碰章号 `[0x476018]`）；
   `0x44e881` 是 `[entry+0x10] −= 8` 的**退一屏**；`0x44e944` 是 `+8` 的**进一屏**；
   `0x44e6eb` 只做「按 `[0x48c5fc]` 取矩形贴图」。谁对应命中表第 2/3 项（170,43 / 170,59 上半部那对三角）
   本轮**没有**回 exe 看跳表 `ref_0044e3e3` 的项序，不下结论。
