## 七、拍賣結算演出（1 个）+ 3 个非 UI 残项（转出）

### 7.1 拍賣結算演出的刷新 / 收攤 `0x0044ee18`（291B / 89 条）

`client/auction-screen.ts` 引它的那一处是「结算演出中点任意处 = 跳过」，
但它本体是**结算演出的计时与收摊**（A 级，全 89 条都在 `db.txt`）：

```asm
0044ee18  push ebx/esi/edi/ebp
0044ee1c  cmp  dword ptr [0x4762c4], 0      ; ★ 演出计时器句柄
0044ee23  je   0x44ef2a                    ;   没在演出 → 直接返回 1
0044ee29  test byte ptr [esp + 0x14], 1     ; ★ 入参 bit0 = 立刻收摊（玩家点了）
0044ee2e  je   0x44ee3f
0044ee30  call 0x454493                    ;   杀掉计时器
0044ee37  mov  dword ptr [0x4762c4], 0
0044ee3f  call dword ptr cs:[0x46246c]      ; ★ WINMM!timeGetTime（不是 GetTickCount）
0044ee46  sub  eax, [0x4762c4]
0044ee4e  cmp  eax, 0x7d0                  ; ★ 2000 ms 上限
0044ee53  jb   0x44ee5f
0044ee5f  test ecx, ecx / jne 0x44ee76      ; 计时器还在 → 什么都不做
0044ee63  cmp  byte ptr [0x49715b], 0       ; 否则问「还要不要继续演」
0044ee6c  call 0x4544b9                    ;   要 → 起一个新计时器
0044ee76  cmp  dword ptr [0x4762c4], 0
0044ee7d  jne  0x44ef34                    ; ★ 仍在演 → 返回 0
0044ee83  ...                              ; 收摊：还原背景 + 释放
0044eeb4  call 0x4563f5                    ;   blitRect（把存下来的那幅贴回去）
0044eec3  call 0x456e11                    ;   my_free
0044eee2  test byte ptr [esp + 0x14], 2     ; ★ 入参 bit1 = 只收摊、不还原背景
0044ef1a  call dword ptr [edx + 0x1c]       ;   DirectDraw Blt
0044ef2a  mov  eax, 1 / ret                 ; ★ 返回 1 = 演出还在（或本来就没在演）
0044ef34  xor eax, eax / ret                ; ★ 返回 0 = 已收摊
```

| 事实 | 值 |
|---|---|
| 计时器句柄 | `[0x4762c4]`，`0x7d0` = **2000 ms** 上限 |
| 入参 bit0 | 立刻收摊（对应「点任意处跳过」）|
| 入参 bit1 | 收摊但**不还原背景** |
| 返回值 | **1 = 还在演出**（或无事可做）、**0 = 已收摊** |
| 时间源 | `cs:[0x46246c]` = **`WINMM!timeGetTime`**（`db.txt` 的 .idata 解析）|

> ⚠️ **PRD 内部的一处笔误（本条顺带订正）**：`cards.md` 与其它小节有
> 「`cs:[0x46246c]` = `GetTickCount`」的写法。二者是**两个不同的导入**：
> `0x4623cc` → `KERNEL32!GetTickCount`、`0x46246c` → `WINMM!timeGetTime`。
> 见 `db.txt` 第 529 行与第 2114 行。
