## 三、樂透 / 抽獎 / 輪盤 / 小遊戲 / 魔法屋（15 个）

> 本节收口阶段 1：这些函数 remake 早已引用，PRD 此前未收。全部是**表现层**（动画 / 版式 / 命中），
> 不承载规则。证据等级：**A** = exe 逐字；**B** = 由 A 级事实直接推出（括注依据）；
> **C** = 仅 remake 注释转述、本轮未回 exe 复核。

范围 = `rich4-spec/tools/scratch/gap-g2-lottery-minigame.txt` 里的 **15 个 VA**（不多不少）。
汇编一律引自 `prd-gap-pack.txt` 对应段落的「asm 前 40 条」，表地址 / 坐标 / 状态机编号引自 pack 与
各屏源文件（`lottery-screen.ts` / `lottery-draw-screen.ts` / `minigame-screen.ts` / `magic-screen.ts` /
